## Sobre “Ya se instaló esta app”
Ese aviso es de Chrome/Android e indica que el navegador ya reconoce una instalación de esa aplicación/origen. Toca la primera opción “Ya se instaló esta app” para abrirla. Si quieres instalarla de cero, busca “Poster Maker” en el cajón de aplicaciones y desinstálala; después vuelve a Chrome y usa “Instalar aplicación”. Si no aparece en el cajón, revisa Ajustes de Android → Aplicaciones → busca “Poster Maker” o Chrome/Aplicaciones instaladas.
