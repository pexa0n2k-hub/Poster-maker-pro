# POSTER MAKER PRO v2.1 — Navegación por apartados

Novedades:
- Menú principal con tres páginas: Diseñador, Laboratorio y Asistente de impresión.
- Diseñador conserva carga de imagen, mejora normal/IA, dimensiones, división, vista previa y exportación.
- Laboratorio agrupa comparador, análisis de DPI, simulador de resolución y zoom de detalles.
- Asistente de impresión queda en su propia página con objetivos DPI, tamaño recomendado y estimación de hojas.
- La imagen y configuración se mantienen en memoria al cambiar de apartado.

Publicación: sube todos los archivos de esta carpeta a la raíz del repositorio GitHub Pages, sustituyendo los anteriores.
